- 연속공격으로 몰려오는 적들을 처치해라! ⚔️<br>
공격이 끝나는 정확한 타이밍에 공격버튼을 입력하면 더 강력하고 넓은 범위의 3연타 공격이 시전됩니다.
- 다양한 스킬들을 활용해라! 🏄🏻<br>
강력한 범위 공격, 돌진 공격, 일정시간 받는 피해를 반감시켜주는 배리어 등 다양한 스킬을 활용해보세요.
- 선택과 집중 🎯<br>
웨이브가 지나갈 수록 적들은 더 강해집니다. 적을 처치해 얻은 보상으로 어떤 스탯과 스킬을 강화할지 잘 선택하세요
